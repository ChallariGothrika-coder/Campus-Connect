About CampusConnect

A smart campus companion for students.

What is CampusConnect?

CampusConnect is a student-friendly website that brings campus announcements, class timetables, college events, lost-and-found notices, and campus locations into one place.

Problems it aims to solve

  • Information scattered across notice boards, emails, and messaging groups.
  • Students missing important announcements or events.
  • Difficulty finding campus locations for new students.
  • No single, quick place to report lost or found items.

Key features

  • Dashboard with summary cards and quick actions.
  • Interactive weekly timetable view.
  • Filterable announcements with categories and priorities.
  • Events with local registration interest and duplicate prevention.
  • Lost & Found with browser-stored user posts.
  • Campus directory of common locations.
  • Global search across all content.

Technologies used

HTML5, CSS3, and Vanilla JavaScript. Data is stored in the browser using localStorage. No backend or paid services are required for this version.

Future improvements

  • Official college authentication and student accounts.
  • A shared database so data is consistent across users and devices.
  • Administrator controls for posting official announcements.
  • Real campus maps with verified location coordinates.
  • Push notifications for important notices.

Data and limitations

All announcements, events, timetable entries, and sample lost-and-found posts are demonstration data. User-created lost-and-found posts are saved only in this browser and are not shared with other users or devices. Registration for events is a local demonstration feature, not an official college registration system.

Reset demonstration data

This clears user-created lost-and-found posts and event registrations stored in this browser. Sample data remains available.
